# Object-Oriented Concepts Lab

This repository contains Java lab exercises and programming projects
completed as part of the Object-Oriented Concepts Lab course.

## Contents

| Directory | Description |
|---|---|
| Lab-02 | Bank Account and Student Stack/Queue exercises |
| Lab-03/RideNow | Ride-sharing system |
| Lab-04/CineCart | Cinema ticket booking and concession management |
| Lab-07/Relay | Messaging and relay system |
| Lab-08/GridLedger | Electricity billing and connection management |
| Lab-09/TakaLink | Digital wallet and transaction management |
| Lab-10/Sketchpad | Shape drawing and object-oriented design |
| Lab-11/KenaKata | Shopping and product catalog system |
| Lab-13/Dokan-Starter | Inventory and shop management |
| Lab-Final/Car-Parking | Car parking management system |

## Technologies

- Java
- Object-Oriented Programming (OOP)
- Gradle
- JUnit testing

## Key Concepts

- Classes and objects
- Encapsulation and inheritance
- Polymorphism and abstraction
- Interfaces and exception handling
- Collections and data management
- Unit testing

## Purpose

The repository serves as a collection of coursework exercises
and projects demonstrating the application of object-oriented
programming principles in Java.
